# Информационная система для планирования и контроля процессов и учета работ по нанесению дорожной разметки

Дипломный проект по специальности «Автоматизированные системы обработки информации» (АСОИ).

## О проекте
Система класса ERP-lite, предназначенная для цифровизации процессов планирования, выполнения и отчетности при нанесении дорожной разметки. Проект связывает работу диспетчеров (офис) и мастеров/бригадиров (объект), обеспечивая геопривязку задач, календарное планирование и автоматическую генерацию актов выполненных работ.

**Автор:** Павел Козицкий

## Основной функционал (MVP)
* **Интерактивная карта:** Установка геометок и прорисовка участков работ (интеграция с Leaflet).
* **Календарное планирование:** Распределение заявок между бригадами (drag&drop).
* **Рабочее место мастера:** Адаптивный мобильный интерфейс для просмотра задач, смены статусов и загрузки фотоотчетов с объекта.
* **Документооборот:** Автоматическая генерация PDF-актов выполненных работ.
* **Ролевая модель:** Разграничение прав доступа (Администратор, Диспетчер, Мастер).

## Стек технологий
* **Backend / Frontend:** ASP.NET Core (Blazor Server), C#
* **База данных:** PostgreSQL + Entity Framework Core
* **Карты / Геоданные:** Leaflet (JS Interop)
* **Аутентификация:** ASP.NET Core Identity
