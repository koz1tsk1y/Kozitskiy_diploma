# Маршруты (user flows) - ИС «Дорожная разметка ERP-lite»

1. Идентификация (вход в систему)
   * Диспетчер / Менеджер: логин → рабочее пространство (дашборд) с интерактивной картой заявок, списком текущих задач и календарем.
   * Мастер / Инженер (Бригадир): логин → мобильно-адаптированный вид со списком своих объектов на сегодня и картой.
   * Администратор: логин → панель управления пользователями, ролями и системными настройками.
2. Подготовка данных и ведение справочников (Администратор)
   * Создание учетных записей пользователей и назначение ролей.
   * Заполнение базовых справочников: типы работ (продольная разметка, пешеходные переходы, дублирование знаков), материалы (краска, термопластик, стеклошарики).
   * Формирование списка доступных бригад и техники.
3. Создание и маршрутизация заявки (Диспетчер)
   * Создание новой сущности «Заявка» (Job/Task).
   * Заполнение основных полей: заказчик, сроки, тип и объем планируемых работ.
   * Работа с картой (Leaflet): установка точной геометки (маркера) или прорисовка линии участка дороги, где будут проводиться работы.
   * Прикрепление исходной документации (схемы ОДД, ТЗ заказчика).
   * Статус заявки: «Новая».
4. Планирование ресурсов и времени (Диспетчер)
   * Переход в модуль календаря.
   * Использование drag&drop для перетаскивания новых заявок на конкретные даты и назначение на определенную бригаду/Мастера.
   * Проверка конфликтов (накладок) в расписании бригад.
   * Перевод заявки в статус: «Запланировано» / «В работе».
5. Выполнение работ и фиксация факта (Мастер)
   * Открытие списка запланированных задач на смену.
   * Просмотр координат и геопривязки задачи на карте.
   * После завершения нанесения разметки: открытие карточки заявки для внесения фактических данных.
   * Прикрепление фотоотчета с места выполнения работ.
   * Указание фактически затраченных материалов или отклонений от первоначального плана.
   * Смена статуса на: «Выполнено» / «Ожидает проверки».
6. Обработка результатов и формирование акта (Диспетчер)
   * Получение уведомления о выполненной заявке.
   * Визуальный контроль прикрепленных фотоотчетов и сверка фактических объемов.
   * Нажатие кнопки «Сформировать акт» - система генерирует печатную форму акта выполненных работ (PDF/Excel) на основе данных из заявки.
   * Смена статуса на: «Закрыто» / «Акт подписан».
7. Отчёты и статистика (Диспетчер / Администратор)
   * Фильтрация заявок по датам, статусам, типам работ или конкретным бригадам.
   * Экспорт отфильтрованного списка в Excel/CSV для дальнейшей аналитики или передачи в бухгалтерию.
   * Просмотр журнала событий по конкретной заявке (кто создал, кто менял статус, кто закрыл).
