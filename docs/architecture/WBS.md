# WBS (эпики → фичи → задачи) - ИС «Дорожная разметка ERP-lite»

* **Эпик A. Модель данных и проектирование БД**
  * **Фичи:** схемы для сущностей User (Пользователи), Job (Заявки), Location (Геометки), Act (Акты), Dictionary (Справочники материалов и техники); настройка миграций.
  * **Задачи:** \* A1. Спроектировать ER-диаграмму и описать связи сущностей.
    * A2. Настроить контекст БД через Entity Framework Core и написать начальные миграции.
    * A3. Подготовить сидирование (seeding) БД тестовыми данными для разработки.
* **Эпик B. Сервисный слой и бизнес-логика (Blazor Server / API)**
  * **Фичи:** CRUD-операции, логика управления статусами, формирование документов.
  * **Задачи:** \* B1. Реализовать базовые сервисы для CRUD заявок и справочников.
    * B2. Написать логику валидации и смены статусов заявок (от «Новая» до «Закрыто»).
    * B3. Реализовать модуль генерации актов выполненных работ (конвертация HTML-шаблона с данными в PDF).
* **Эпик C. Интерактивная карта и геопривязка**
  * **Фичи:** интеграция Leaflet, работа с координатами объектов разметки.
  * **Задачи:** \* C1. Настроить JS Interop в Blazor для взаимодействия с библиотекой Leaflet.
    * C2. Реализовать отображение существующих заявок (маркеров и полилиний) на карте с попапами.
    * C3. Добавить функционал установки геометок при создании или редактировании заявки диспетчером.
* **Эпик D. UI: Календарь планирования и рабочие места**
  * **Фичи:** дашборд, расписание бригад, интерфейс для мобильных устройств.
  * **Задачи:** \* D1. Интегрировать библиотеку календаря (например, FullCalendar) для дашборда диспетчера.
    * D2. Реализовать функционал drag&drop в календаре для назначения заявок на даты и бригады.
    * D3. Сверстать адаптивный (мобильный) вид карточки задачи для мастера, включая форму загрузки фотоотчета.
* **Эпик E. Безопасность и ролевая модель (RBAC)**
  * **Фичи:** аутентификация, авторизация, scope-ограничения.
  * **Задачи:** \* E1. Интегрировать и настроить ASP.NET Core Identity.
    * E2. Реализовать проверку прав доступа на уровне страниц и сервисов (Admin, Dispatcher, Foreman).
    * E3. Настроить фильтрацию выборки из БД, чтобы мастера видели только назначенные на них объекты.
* **Эпик F. Инфраструктура, деплой и документация**
  * **Фичи:** подготовка к защите, публикация приложения.
  * **Задачи:** \* F1. Написать Dockerfile для контейнеризации приложения и БД (PostgreSQL/SQL Server).
    * F2. Развернуть тестовый стенд (на сервере или локально через Docker Compose).
    * F3. Подготовить пользовательские инструкции и техническую документацию для пояснительной записки.
