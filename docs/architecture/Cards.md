# Карточки сущностей (обязательные поля и валидации)

**1) Форма аутентификации**

* login: string, не пустое → ошибка: «Введите логин (имя пользователя).»
* password: string, не пустое → ошибка: «Введите пароль.»

**2) Карточка заявки на разметку (Job)**

* id: UUID, автогенерируется
* customer: string, не пустое → ошибка: «Укажите наименование заказчика.»
* work_type_id: reference -\> Dictionary.id (Тип работ из справочника), не пустое → ошибка: «Выберите тип разметки (например, продольная 1.1).»
* geo_location: string/GeoJSON (данные с карты Leaflet), не пустое → ошибка: «Укажите место проведения работ на карте.»
* deadline: datetime, не пустое → ошибка: «Укажите плановый срок выполнения.»
* foreman_id: reference -\> User.id (Мастер/Бригада), опционально при создании (назначается позже диспетчером при планировании).
* status: enum [Новая, Запланирована, В работе, Выполнена, Закрыта], default: Новая.

**3) Карточка отчета о выполнении (WorkReport - заполняет мастер на объекте)**

* job_id: reference -\> Job.id, не пустое
* photos: array of files, обязательно при переводе статуса в "Выполнена" → ошибка: «Для закрытия заявки прикрепите минимум одно фото результата работ.»
* materials_used: text, опционально (свободный ввод потраченных материалов, например: "150 кг пластика, 20 кг стеклошариков").
* comment: text, опционально (примечания по объекту, сложности).

**4) Карточка акта выполненных работ (Act)**

* id: UUID, автогенерируется
* job_id: reference -\> Job.id, не пустое
* generated_at: datetime, автогенерируется
* document_url: string (ссылка на сгенерированный PDF), автогенерируется.

**5) Карточка пользователя / бригады (User)**

* id: UUID, автогенерируется
* full_name: string, не пустое → ошибка: «Введите ФИО сотрудника или название бригады.»
* role: enum [admin, dispatcher, foreman], не пустое → ошибка: «Выберите роль в системе.»
* is_active: boolean, default: true.
